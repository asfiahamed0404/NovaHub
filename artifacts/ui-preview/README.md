# NovaHub UI previews

Screenshots of the local frontend redesign at desktop and mobile sizes.
Dashboard, conversation, and AI dialog previews use isolated fictional data.
The conversation preview shows the disconnected state because its realtime
transport is not connected to a backend during capture.

- `dashboard-desktop.png`: workspace overview and search
- `dashboard-dark.png`: dark appearance
- `dashboard-mobile.png`: mobile overview
- `login-desktop.png`: shared login and registration layout
- `workspace-desktop.png`: conversation and members
- `workspace-mobile.png`: mobile conversation
- `ask-nova-desktop.png`: Ask Nova dialog

Verified: production build, ESLint, 101 existing frontend tests, browser search
and empty results, create-workspace focus and mocked submission, theme
switching, mobile overflow, and opening/dismissing the AI dialog.
